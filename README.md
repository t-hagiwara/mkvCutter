# MKV Cutter

Windows向けのデスクトップアプリです。動画ファイルと開始・終了時刻を指定し、`mkvmerge` を使って指定範囲を無劣化でMKVファイルに切り出します。

## 主な機能

- 動画をファイル選択ダイアログ、またはドラッグ＆ドロップで指定
- 開始・終了時刻をミリ秒単位で入力
- 出力先とファイル名を指定
- 入力・出力ファイルのパスをダブルクリックして既定のプレイヤーで開く
- `mkvmerge` の実行ログ、日本語を含む標準出力・エラーの表示
- 処理のキャンセル、既存出力ファイルの上書き確認
- 選択した `mkvmerge.exe` のパスを次回起動時に再利用

## 動作に必要なもの

- Windows
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)（ソースからビルドする場合）
- .NET 10 Windows Desktop Runtime（発行済みアプリを実行する場合）
- [MKVToolNix](https://mkvtoolnix.download/) の `mkvmerge.exe`

`mkvmerge.exe` はアプリに同梱されません。別途MKVToolNixをインストールしてください。

## 起動方法

### ソースから起動

リポジトリのルートでPowerShellを開き、実行します。

```powershell
dotnet run --project .\MkvCutter.csproj
```

### Release版の発行

```powershell
dotnet publish .\MkvCutter.csproj -c Release
```

既定の発行先は次のとおりです。

```text
bin\Release\net10.0-windows\publish\
```

発行したアプリを別の場所へ移動する場合は、`MkvCutter.exe` だけでなく、同じ発行フォルダー内の関連ファイルも一緒に移動してください。

## `mkvmerge.exe` の設定

アプリの起動時、次の順番で `mkvmerge.exe` を探します。

1. Windowsの `PATH` に登録されたフォルダー
2. 実行ファイルと同じフォルダーにある `mkvCutter.settings.json`
3. 見つからない場合はファイル選択画面

ファイル選択画面で指定したパスは、実行ファイルと同じフォルダーの `mkvCutter.settings.json` に保存されます。次回起動時に `PATH` から見つからなければ、この設定が使われます。

設定ファイルを保存できないフォルダーで実行した場合、指定したパスは現在の起動中のみ使用できます。設定ファイルはアプリと一緒にフォルダーごと削除できます。また、Git管理対象には含まれません。

## 使い方

1. 「入力動画」の「参照...」を押すか、動画ファイルを入力欄へ1つドラッグ＆ドロップします。
2. 入力動画と同じフォルダーに `<入力名>_cut.mkv` が出力先として自動入力されます。必要に応じて保存先・ファイル名を編集するか、「保存先...」から選びます。
3. 開始時刻と終了時刻を入力します。
4. 「切り出し開始」を押します。処理中はログが表示され、「キャンセル」で停止できます。

入力動画が設定されるまでは「切り出し開始」ボタンは無効です。
入力・出力ファイルのパスをダブルクリックすると、そのファイルが存在する場合は既定のプレイヤーで開きます。

### 時刻の入力形式

`時:分:秒.ミリ秒` の形式で入力します。

```text
00:00:06.500
```

時は2桁以上、分と秒は `00`〜`59`、ミリ秒は3桁で入力してください。終了時刻は開始時刻より後である必要があります。初期値は開始 `00:00:00.000`、終了 `00:01:00.000` です。

## 出力・処理について

- `mkvmerge` は映像・音声を再エンコードせずにMKVへ格納するため、再エンコードによる画質・音質の劣化がありません。処理も比較的高速です。
- ただし、入力した時刻どおりの位置で切れるとは限りません。特に映像はキーフレームなどの境界に制約されるため、実際のカット位置が指定したミリ秒から前後する場合があります。
- フレーム単位で正確な位置を指定したい場合は、再エンコードを行う動画編集ソフトをご利用ください。
- 出力ファイルの拡張子は `.mkv` にしてください。保存先フォルダーは事前に作成されている必要があります。
- 入力動画と同じファイルを出力先には指定できません。
- 出力先と、`mkvmerge` が分割時に付ける連番付きファイル名がすでに存在する場合は、実行前に上書きを確認します。
- アプリは概ね次の形式で `mkvmerge` を実行します。

  ```text
  mkvmerge -o "<出力ファイル>" --split "parts:<開始時刻>-<終了時刻>" "<入力ファイル>"
  ```

- `mkvmerge` の終了コードと実行ログを画面に表示します。ログはUTF-8として読み取ります。
- 実行中にアプリを閉じる場合は確認が表示されます。終了を選ぶと処理中の `mkvmerge` も停止します。

## トラブルシューティング

### 起動時に `mkvmerge.exe` の選択画面が表示される

`mkvmerge.exe` がPATHにも保存済み設定にも見つかりません。MKVToolNixをインストールし、`mkvmerge.exe` を選択してください。

### 次回起動時にもう一度選択を求められる

`mkvCutter.settings.json` をアプリの実行ファイルと同じフォルダーに保存できていない可能性があります。そのフォルダーへの書き込み権限を確認してください。`PATH` に `mkvmerge.exe` のフォルダーを追加する方法もあります。

### 切り出しに失敗する

画面下部の実行ログを確認してください。入力ファイル形式、時刻の範囲、保存先への書き込み権限、既存ファイルの有無も確認してください。

## バージョン

アプリのバージョン番号は [MkvCutter.csproj](MkvCutter.csproj) の `<Version>` で指定します。リリース時にこの値を更新すると、ウィンドウのタイトルバーに反映されます。

- `MkvCutter.csproj` — WPFプロジェクト設定

- `MainWindow.xaml` — メイン画面
- `MainWindow.xaml.cs` — ファイル選択、入力検証、`mkvmerge` の起動とログ表示
